# MoHAA Reloaded: before and after

Screenshots of OpenMoHAA's stock menus and HUD next to MoHAA Reloaded's: the same game, the same renderer and, where
it can be, the same view. The page is `site/index.html`; GitHub Actions publishes it to GitHub Pages on every push to
`main` (`.github/workflows/pages.yml`).
